## 依任務分類

先從「要解決什麼問題」來看，常見的演算法大致可以這樣分：

| 任務 | 代表演算法 |
| --- | --- |
| 分類 | SVM、KNN、單純貝氏分類器、決策樹 |
| 迴歸（預測數值） | 線性迴歸、迴歸樹、KNN 迴歸 |
| 序列建模 | 馬可夫鏈、隱藏馬可夫模型（HMM） |
| 分群 | K-Means、階層式分群 |
| 降維 | 主成分分析（PCA）、因素分析（FA） |
| 關聯規則 | Apriori |
| 決策與控制 | Q-Learning、Deep Q-Learning（DQN） |

## Domingos 的五大學派

另一種分法是看演算法背後的推理邏輯。華盛頓大學的 Pedro Domingos 在《The Master Algorithm》（2015，中譯《大演算》）中，把機器學習的研究者分成五個學派：

| 學派 | 推理準則 | 代表演算法 |
| --- | --- | --- |
| 貝氏學派（Bayesians） | 用機率和貝氏定理處理不確定性 | 單純貝氏、馬可夫鏈、HMM |
| 類推學派（Analogizers） | 根據跟已知例子的相似程度判斷 | KNN、SVM |
| 符號學派（Symbolists） | 用邏輯規則和 if-then 推論 | 決策樹、規則學習、專家系統 |
| 連結學派（Connectionists） | 模仿大腦，用多層連結的神經元學習 | 類神經網路、深度學習 |
| 演化學派（Evolutionaries） | 模仿自然選擇，讓解一代代演化 | 遺傳演算法、遺傳規劃 |

書中沒有非監督式學習和強化學習這兩個「學派」，它們是另一個維度的分類（依學習方式），在後面另外整理。

## 1. 貝氏學派

核心思想：**世界充滿不確定性，用機率表達，看到新證據就更新判斷。**

### 單純貝氏（Naive Bayes）

根據貝氏定理計算「看到這些特徵時，屬於某個類別的機率」，並假設各個特徵彼此獨立。這個假設在現實中幾乎不成立（所以叫 naive），但計算很快，效果也常常不錯。

例如垃圾郵件過濾：統計「免費」「中獎」「點擊」等字詞在垃圾信和正常信中出現的機率，新郵件進來時，把每個字的機率乘起來，看哪一類的機率比較高。

### 馬可夫鏈（Markov Chain）

概念：**下一個狀態只跟現在的狀態有關，跟更早之前無關。**

以天氣為例：

```
今天晴天 → 明天：80% 晴天、20% 下雨
今天雨天 → 明天：70% 下雨、30% 晴天
```

要預測明天，只需要知道今天，不必知道一個月前的天氣。

文字也能這樣產生：「我」後面接「愛」的機率 90%、接「討厭」10%；「愛」後面接「你」60%、「貓」20%、「吃飯」20%，一路依機率抽下去。早期的聊天機器人和輸入法的選字預測都用過這類模型。

### 隱藏馬可夫模型（HMM）

比馬可夫鏈多一層：**真正的狀態看不到，只能看到它產生的觀察值。**

例如醫生不知道病人真正的狀態是「健康」「感冒」還是「肺炎」，只能看到「發燒」「咳嗽」「流鼻水」這些症狀。HMM 根據一連串的觀察值，推測背後最可能的狀態序列。

常見用途：語音辨識（深度學習普及之前的主流做法）、中文斷詞、詞性標註（POS tagging）、DNA 序列分析。

## 2. 類推學派

核心思想：**新資料跟哪些已知例子最像，就做出類似的判斷。**

### KNN（K 近鄰）

非常直覺。假設有這些水果資料：

| 重量 | 顏色 |
| --- | --- |
| 95g | 紅 |
| 100g | 紅 |
| 110g | 紅 |
| 300g | 黃 |
| 310g | 黃 |

來了一顆 105g 的新水果，找最近的三筆（100g、110g、95g），全部都是紅色，所以判斷為紅色。

KNN 也能做迴歸：附近三間房子分別賣 1000 萬、1100 萬、980 萬，你的房子就估約 1027 萬（三者的平均）。

- 優點：不需要訓練，資料存起來就能用。
- 缺點：每次預測都要跟所有資料比距離，資料量大時很慢；特徵的尺度不同時，也要先做標準化。

### 支持向量機（SVM）

核心思想：**找一條最好的分界線。**

```
○ ○ ○ ○
─────────
× × × ×
```

能分開兩類的線有很多條，SVM 找的是**離兩邊最近的點最遠**的那一條，也就是 maximum margin（最大間隔）。資料無法用直線分開時，可以用 kernel trick 把資料映射到更高維的空間再找分界。垃圾郵件分類、文字分類都是 SVM 的常見應用。

## 3. 符號學派

核心思想：**把知識表示成符號和邏輯規則，用推論得出結論。**

早期的專家系統就是由人把規則寫下來，例如：

```
IF 收入 > 5 萬 AND 信用正常 AND 年齡在 20~60 歲
THEN 核准貸款
```

規則全部由人撰寫，容易解釋，但規則一多就難以維護。機器學習版的符號學派，則是讓電腦**從資料中自己學出規則**，決策樹就是代表。

### 決策樹（Decision Tree）

像玩「20 個問題」，一路問問題直到得出答案。例如判斷某人會不會買電腦：

```
收入高？
├─ 是 → 買
└─ 否 → 是學生？
        ├─ 是 → 買
        └─ 否 → 不買
```

要問哪些問題、門檻設多少，是演算法從資料中找出來的。這一點跟手寫的規則不同：例如物件偵測後處理常見的「信心值 > 0.7 且面積 > 500 就保留」，雖然長得像一棵樹，但它是人定的規則，不是學出來的決策樹。

優點是很好解釋，缺點是單一棵樹容易 overfitting。

### 集成學習：很多棵樹一起投票

不要只相信一棵樹，讓很多棵樹一起投票。

- **Bagging（袋裝法）**：從訓練資料中有放回地抽樣（bootstrap），每棵樹用不同的抽樣訓練，最後投票。例如五棵樹的結果是「狗、狗、狗、貓、狗」，就判斷為狗。這樣可以降低變異，減少 overfitting。
- **隨機森林（Random Forest）**：Bagging 的進階版。除了每棵樹用不同的抽樣，**每次分岔時也只從隨機挑選的一部分特徵中找最佳切點**。例如判斷水果時有重量、顏色、甜度、大小四個特徵，某個節點可能只考慮重量和甜度，另一個節點只考慮顏色和大小。這讓每棵樹更不一樣，投票的效果更好。

隨機森林在表格資料的工業應用上很受歡迎：不太需要調參數、訓練快、效果穩定，也能算出特徵重要度。不過幾百棵樹一起投票，就不像單一棵樹那樣能直接看懂判斷過程。

## 4. 連結學派

這就是今天最熱門的一派：**神經網路**。

### 核心理念：不是人教規則，而是從經驗中學

連結學派跟規則式方法最大的不同是：**不是人把規則教給電腦，而是讓電腦從大量例子中自己找出規律。**

想想小朋友怎麼學會認貓。你不會跟他說「四隻腳、有鬍鬚、耳朵尖、尾巴長的就是貓」，而是一次又一次指給他看：「這是貓」「這也是貓」。看過幾百次之後，就算遇到花色、大小、胖瘦、毛長都不一樣的貓，他還是認得出來。但如果問他為什麼，他多半說不上來，只是「感覺就是貓」。

認人也一樣。爸爸戴帽子、戴口罩、剪頭髮、換西裝，你都還認得。你依靠的不是「頭髮長 = 爸爸」或「有鬍子 = 爸爸」這種單一規則，而是把臉型、眼睛、聲音、身高、走路方式等很多特徵綜合起來判斷。

神經網路做的就是這件事：**從大量例子中學會綜合判斷，而且能套用到沒看過的新例子上**，這叫做泛化（generalization）。就像學加法不是背下「1+1=2、2+2=4」，而是理解規則後，連「100+100」也會算。

### 為什麼叫「連結」

因為它模仿大腦的神經元：很多神經元分成好幾層，每一層把處理過的資訊傳給下一層。以辨識一張貓的照片為例，研究者把訓練好的卷積網路視覺化後，觀察到類似這樣的分工：

```
第一層：找到邊緣、顏色、明暗
第二層：組合成紋理和簡單形狀
第三層：組合成眼睛、耳朵等部位
更深層：組合成臉，最後判斷「這是貓」
```

越後面的層，表示的概念越抽象。這就是深度學習的「深度（Deep）」：**不是資料很多，而是層數很多**。

### 淺層神經網路與深度學習

- **淺層神經網路**：只有一兩個隱藏層。例如辨識 MNIST 手寫數字：784 個輸入（28×28 像素）→ 128 個隱藏神經元 → 10 個輸出（數字 0~9）。
- **深度學習**：很多很多層，例如 `圖片 → 多層卷積（CNN）→ Transformer → 輸出`。YOLO、ResNet、EfficientNet、ViT、大型語言模型（LLM）都是深度學習模型。

### 為什麼現在 AI 都用深度學習

因為很多事情根本寫不出規則。試著寫規則辨識狗：四隻腳、有尾巴、有耳朵……但狐狸和狼也符合，而哈士奇、吉娃娃、黃金獵犬又長得完全不一樣，規則永遠寫不完。所以改成給模型看大量標註好的狗照片，讓它自己學。代價是需要大量資料和運算資源，而且模型的判斷過程不容易解釋。

## 5. 演化學派

核心思想：**模仿自然演化，讓好的解存活、繁衍、突變。**

### 遺傳演算法（GA）

```
產生 100 個隨機的解 → 評分 → 留下最好的
→ 交配（交換片段）→ 突變（隨機修改）→ 下一代 → 重複
```

例如旅行推銷員問題（TSP）：每個解是一條拜訪城市的順序（ABCDE、BACDE、CADBE……），每一代留下總距離較短的路線，再交配、突變出新路線。

AI 實務上也常拿來調超參數。例如 Ultralytics YOLO 的超參數調整就是用演化的方式，讓 learning rate、momentum 等參數一代代突變，留下表現最好的組合。

## 6. 依學習方式分類：非監督式學習與強化學習

Domingos 的五大學派是依「推理邏輯」分類。現代教科書更常依**學習方式**分類：監督式學習、非監督式學習、半監督式學習、自監督式學習與強化學習。下面兩種常被放進同一張圖，但它們不是 Domingos 的學派。

### 非監督式學習：沒有答案，自己找規律

**K-Means（分群）**：例如把 100 位客戶依年齡和收入分成三群，事後可能會發現分別對應學生、小資族、高收入族，但資料本身沒有任何標籤。

```
隨機放 K 個中心 → 每個點分給最近的中心
→ 用各群的平均重新計算中心 → 重複直到中心不再移動
```

**PCA（主成分分析，降維）**：把 100 個特徵壓縮成 5 個，同時盡量保留資料的變異（資訊）。例如一張 1920×1080 的灰階影像有約 207 萬個像素，等於 207 萬維，PCA 可以大幅壓縮。PCA 也常用來把高維資料畫成 2D 或 3D 圖。

### 強化學習：從獎勵中學策略

強化學習不是學「正確答案」，而是透過試錯學習策略：

```
做出動作 → 得到獎勵（reward）→ 調整策略 → 重複
```

例如下棋：贏了 +1，輸了 −1，下得越多越強。DeepMind 的 AlphaGo（2016）先用 3000 萬步人類棋譜做監督式學習，再透過自我對弈的強化學習變強，下棋時搭配蒙地卡羅樹搜尋；後來的 AlphaGo Zero 則完全不用人類棋譜。其他應用還有機器人行走、自駕車、遊戲 AI。

## 實際系統：多種演算法的組合

以一個從攝影機畫面辨識車牌的系統為例：

```
RTSP 攝影機
  ↓
YOLO 偵測車輛與車牌（深度學習，連結學派）
  ↓
ByteTrack 多目標追蹤（卡爾曼濾波預測位置 + 匈牙利演算法做資料關聯）
  ↓
PaddleOCR 辨識車牌文字（深度學習）
  ↓
業務規則（規則式邏輯），例如：
- 車頭先觸發前線、車尾觸發後線
- 同一個 Track ID 只存一次
- 信心值低於 0.5 就捨棄
```

可以看到，**實際的 AI 系統通常不只用一種演算法，而是把深度學習、追蹤演算法和規則式邏輯組合起來**：YOLO 和 OCR 負責「感知」，ByteTrack 負責「關聯」，觸發線、快取、事件判斷這些程式則是規則式邏輯，負責完成整個業務流程。

## 總整理

| 分類 | 核心概念 | 代表演算法 | 常見應用 |
| --- | --- | --- | --- |
| 貝氏學派 | 用機率處理不確定性 | 單純貝氏、馬可夫鏈、HMM | 垃圾郵件過濾、語音辨識（早期）、斷詞 |
| 類推學派 | 找最相似的例子 | KNN、SVM | 分類、迴歸、推薦 |
| 符號學派 | 用邏輯規則推論 | 專家系統、決策樹、隨機森林 | 信用評分、醫療診斷、工業預測 |
| 連結學派 | 用神經網路從資料學特徵 | ANN、CNN、Transformer、YOLO | 電腦視覺、語音辨識、LLM |
| 演化學派 | 模仿自然演化 | 遺傳演算法、遺傳規劃 | 最佳化、超參數搜尋 |
| 非監督式學習 | 在無標籤資料中找規律 | K-Means、PCA | 分群、降維、異常偵測 |
| 強化學習 | 從獎勵中學策略 | Q-Learning、DQN | 遊戲、機器人、AlphaGo |

最後補充一點：五大學派是一種偏歷史觀點的分類，用來理解各派的思想源流很好用，但實務上的歸類並不絕對。例如隨機森林常被歸在集成學習而不是符號學派，強化學習也不屬於任何一派，而 Domingos 自己的主張正是要把各派的優點結合成一個「終極演算法」。
